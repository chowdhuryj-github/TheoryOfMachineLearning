# Theory Of Machine Learning
Welcome to the MSOE Machine Learning Repository. This is a collection of my work ranging from Week 1 to Week 12. In this repository, I explore all 
machine learning concepts ranging from modeling methods like Gaussian Distribution to using Optimization Methods like SGD! Each directory covers a 
concept that is listed as follows:

## Week 1 | Introduction To Machine Learning
In [Week 1](1_week-one), I explored what machine learning is, the different types of machine learning problems, what it means to fit a machine learning model as well as the several use cases for machine learning.

## Week 2 & 3 | Modeling & Model Error
In [Week 2](2_week-two) and [Week 3](3_week-three), I learn how to build simplemachine learning models by working with datasets, implement a Gaussian distribution, multiple linear regression model and visualizing as how well they match the real data. I also measure the accuracy of the models using error metrics such as Mean Absolute Error (MAE) and etc.

## Week 4 | Decision Boundaries
In [Week 4](4_week-four), I visualize and evaluate the decision boundaries to see how well they separate different classes in a dataset, using simple linear equations and accuracy as a metric. I explore splitting data into training, testing and validation sets as a way to avoid overfitting to better estimate how a model will perform on new data. 

## Week 5 | K-Nearest Neighbors
In [Week 5](5_week-five), I look at how the k-nearest neighbors (KNN) algorithm works by having to implement it from scratch and use it to classify and predict data, including visualizing non-linear decision boundaries. I also adjust the `k` to see how it impacts the model performance and using tehcniques like cross-validation as a way to select good parameters.

## Week 6 | Feed Forward Neural Network
In [Week 6](6_week-six), I use a feedforward neural network (MLP) to train it on a dataset and then visualize the each individual neuron to create decision boundaries. I then evaluate the performance of the network using metrics such as the ROC and AUC curve. 

## Week 7 | Feed Forward Neural Network
In [Week 7](7_week-seven), I work on problem sets relating to logistic regression and decision trees by analyzing the decision boundaries, calculating the liklihoods, interpreting model weights as well as evaluating the splits using the Gini index. 

## Week 8 | Support Vector Machines
In [Week 8](8_week-eight), I explore how Support Vector Machines (SVMs) work by adjusting the penalty parameter `C` to see how it affects decision boundaries, margins and support vectors. I also look at how kernel methods transform data into higher dimensions to make non-linearly separable data linearly separable. 

## Week 9 | Cost Functions & Parameter Space
In [Week 9](9_week-nine), I use cost functions to measure model error and find better model parameters using grid search instead of guessing. I then visualize how these parameter choices affect the error and understand the challenges of searching for optimal parameters in higher-dimensional models. 

## Week 10 | Analytical & Numerical Differentiation
In [Week 10](10_week_ten), I use analytical and numerical derivatives to understand how functions change and to find their minimum and maximum values without grid searching. I instead use gradients for multi-dimensional problems as way to work towwards optimal model parameters.

## Week 11 | Cost Function Fun
In [Week 11](11_week_eleven), I work with Ridge & Lasso Regularization to prvent overfitting in the model by simply shrinking the model weights and changing how the regularization strength affects the training error, test error and the bias-variance trade-off. I use a synthetic dataset to fit the 
Ridge & Lasso regression with different regularization values, as well as looking at coefficient norms and cross-validation to pick the best model. 

## Week 12 | Gradient Descent
In [Week 12](12_week_twelve), I implement a gradient descent optimizer and then use it to minimize different functions such as cubic, quartic and a gaussian model. I experiment with different starting points and how the parameters affect the results, analyzing how the algorithm behaves.
